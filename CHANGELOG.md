# Changelog

All notable changes to Family Archive are recorded here. The full group-by-group
history is available in [Release History](docs/RELEASE_HISTORY.md).

## [3.8.0] - 2026-08-02

### Added

- A deterministic 30,000-entry synthetic migration qualification manifest.
- Durable bounded checkpoints, interruption recovery and isolated retry handling.
- Exact reconciliation, idempotent replay protection and a private migration boundary.
- Repository release-state and evidence verification.

### Changed

- Closed Screenshot Groups 01-33 and moved the product into maintenance and real
  migration readiness.
- Updated CI to verify supported PHP versions independently and run dependency,
  application and release-integrity gates.

### Security

- Public evidence remains synthetic and excludes credentials, private media,
  absolute source paths and production storage identifiers.

## [3.0.0 - 3.7.0]

The 3.x releases consolidated role-aware workflows, original-first manual
restoration, interactive maps, albums, guided family access, everyday family
language, embedded messaging and migration preflight.

## [2.0.0 - 2.9.0]

The 2.x releases established hosted production, unified member and owner
experiences, verified photo processing, high-volume intake and delegated family
operations.

## [1.0.0 - 1.9.0]

The 1.x releases closed the first complete preservation product and added media
intelligence, cloud import planning, public discovery, controlled community
features, accounts, restoration automation and Wasabi production storage.

## [0.20.0 - 0.44.0]

The foundational releases implemented archive knowledge, family access,
collaboration, restoration, integrity and production-readiness boundaries.
