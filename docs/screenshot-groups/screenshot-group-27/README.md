# Screenshot Group 27 — Interactive Archive Map

This evidence pack covers the v3.2.0 Interactive Archive Map boundary.

It demonstrates a real Google map containing only published,
privacy-reviewed, deliberately reduced location points. It also demonstrates
that Photos, Places, Map, People, Events, Branches and Search share one stable
navigation position throughout archive exploration.

The evidence uses fictional identities, records and locations. Exact archive
coordinates, private records and unreviewed locations are excluded before the
browser payload is created.
