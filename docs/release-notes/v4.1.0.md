# Family Archive v4.1.0

Clipping-Safe Photo Separation closes Screenshot Group 36.

This release makes separated-photo rendering geometry safe: each proposed
child is extracted onto a padded working canvas, independently rotated or
deskewed, and only then cropped to its final content bounds. A reviewer can
override the proposed orientation in 90-degree steps without changing the
immutable source scan.

## Evidence

- Approved Screenshot Group 36 demonstrates clipping-safe processing order,
  independent child rotation, rotated preview geometry, manual rotation,
  immutable source lineage and responsive split review.
- Automated tests cover the renderer and multi-photo split workflow.
- The public evidence pack contains synthetic data only.

The real private family migration remains explicitly incomplete and outside
the public evidence boundary.
