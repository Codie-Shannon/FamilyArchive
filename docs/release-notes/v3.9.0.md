# Family Archive v3.9.0 — Composite Photo Separation

Released: 2026-08-03

Version 3.9.0 closes Screenshot Group 34. It adds an original-first workflow
for detecting, reviewing and separating scans that contain multiple distinct
photos without changing the preserved source object.

## Separation evidence

- Confidence-based suggestions for common two- and four-photo layouts
- Detection that does not depend on white gutters between photos
- Review routing for uncertain layouts instead of silent splitting
- A free-form editor for adding, moving, resizing and excluding regions
- Independent child previews rendered from the verified original
- Explicit source-version and region lineage for every published child photo

## Preservation boundary

The composite source remains immutable. Suggested and manually adjusted regions
are reversible review data until accepted, and published children are new
versioned archive objects rather than replacements for the original.

## Product state

Screenshot Groups 01-34 are approved and closed. The real private family
migration remains incomplete and outside public evidence. Composite separation
is ready before that migration begins so multi-photo source files can be routed
through human review safely.

## Known limits

- Layout detection is assistive; ambiguous sources require a human decision.
- Photo preservation is complete; other media types are not complete pipelines.
- Google Maps, Wasabi and hosted production rely on externally operated services.
- Formal family acceptance, custodianship and recovery exercises remain human work.
