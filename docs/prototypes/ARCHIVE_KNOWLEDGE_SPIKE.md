# Archive Knowledge Integration History

The generated Archive Knowledge spike supplied the common v0.20.0 release
surface for Screenshot Group 01, which covers Build Groups 13–20. It is now
the active, verified Owner-only Archive Knowledge hub rather than a disabled
prototype.

## Canonical Boundary

- Screenshot Group 01 is one generated release boundary, not eight screenshot
  groups.
- Its release is v0.20.0, Archive Knowledge, covering Build Groups 13–20.
- Implementation and the approved six-file evidence pack are complete.
- Screenshot Groups 02–11 remain separate later packs.

## Hardened Knowledge Surface

The active `/archive/knowledge` route and navigation entry require a verified
Owner. Counts and search results include only reviewed records and exclude
living people, private identities, sensitive or private locations and merged
identities. The surface never returns original paths, hashes or EXIF GPS.

## Additive Schema History

The shared schema migration remains unchanged. Later additive migrations
harden its generated tables without rewriting migration history:

- event and location records gained review, privacy, provenance and immutable
  revision controls;
- person and family-branch records gained uncertainty, review, privacy,
  provenance and immutable revision controls; and
- incomplete relationship, person-media, merge and resolution workflows
  remain outside the visible hub.

Schema presence alone does not expose a workflow. Human review and the private
Owner boundary remain mandatory.
